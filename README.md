# SAFE-FLOOD - ระบบสนับสนุนออฟไลน์ยามอุทกภัย (เขตบางพลัด)

แอปพลิเคชันเว็บแบบ Single Pageที่ออกแบบมาเพื่อช่วยเหลือและเตรียมความพร้อมในการอพยพผู้ประสบภัยน้ำท่วมในเขตบางพลัด ทำงานได้สมบูรณ์แบบ 100% แม้อยู่ในสถานะออฟไลน์ (Offline) สัญญาณอินเทอร์เน็ตล่ม หรือไฟฟ้าหลักดับทั้งหมด

---

## จุดเด่นของโครงการ 

1. **ระบบสลับสถานะเครือข่ายแบบเรียลไทม์ (Online/Offline Toggle with Loading Handshake)**
   * จำลองขั้นตอนการเจรจาสัญญาณกับดาวเทียม (Grid Connect) หรือการสับเปลี่ยนมาใช้แบตเตอรี่และคลื่นวิทยุสำรอง (Crisis Disconnect) พร้อมแอนิเมชัน Handshake หน่วงเวลา 800ms เพื่อความสมจริงในการจับคลื่นสัญญาณ
   * ปรับเปลี่ยนรูปแบบ UI และชุดสีตามสถานะเครือข่ายโดยอัตโนมัติ (Online = ธีมส้ม/น้ำเงินพรีเมียม, Offline = ธีมเหลืองสะท้อนแสง/ดำ OLED เพื่อประหยัดพลังงานโทรศัพท์)

2. **ระบบเนวิเกชันแบบยืดหยุ่น (Adaptive Bottom Navigation)**
   * **โหมดออนไลน์ (Online)**: ซ่อนแถบเมนูด้านล่างทั้งหมดเพื่อให้ผู้ใช้จดจ่อกับข้อมูลสภาพน้ำ แผนที่ และสถานะทางอากาศที่สดใหม่จาก API ภายนอกได้อย่างเต็มตา
   * **โหมดออฟไลน์ (Offline)**: แสดงแถบนำทางด่วนด้านล่างเพื่อเข้าถึง "ห้องแชทช่วยเหลือรวมศูนย์" ทันที

3. **แผงแชทช่วยเหลือและค้นหาคู่มือรวมศูนย์ (Unified Command Chat Center)**
   * รวบรวมแผง "ค้นหาคู่มือออฟไลน์" และ "วิทยุเพื่อนบ้าน (Mesh Chat)" ไว้บนหน้าจอเดียวกัน ช่วยลดความยุ่งยากในสถานการณ์ฉุกเฉิน
   * ย้ายปุ่มทางลัดหมวดหมู่คู่มือ ( ปฐมพยาบาล,  อพยพ,  ไฟฟ้า,  น้ำ/สุขา,  เบอร์ติดต่อ) มาไว้ที่ขอบล่างของหน้าจอเพื่อให้กดได้ง่ายและปลอดภัยด้วยนิ้วโป้งเพียงข้างเดียว (Thumb-Friendly Design)

4. **คู่มือออฟไลน์แบบละเอียด 13 บทปฏิบัติการจริง (13-Chapter Offline Survival Manual)**
   * คลังความรู้ภาษาไทยเพื่อช่วยชีวิตตนเองและคนรอบข้างในสถานการณ์จริงที่ไม่มีเน็ต
   * ระบบค้นหาอัจฉริยะ (Advanced Synonym Router) สามารถพิมพ์ข้อความค้นหาด้วยคำพ้อง, คำทับศัพท์ภาษาอังกฤษ, ตัวเลข หรือกรณีพิมพ์ผิดบางส่วน (เช่น คอนแทค, cpr, เบรกเกอร์, งู, โรงพยาบาล) พร้อมระบบแนะนำคำค้นหาเมื่อไม่พบข้อมูล

5. **ระบบจำลองสัญญาณวิทยุเพื่อนบ้าน (Simulated Local Mesh Network)**
   * คุยกับเพื่อนบ้านรอบข้างจำลองระยะส่งสัญญาณ 350 เมตรผ่านเทคโนโลยี Wi-Fi Direct / Bluetooth โดยไม่ต้องพึ่งเครือข่ายโทรศัพท์หลัก
   * มีระบบ **"ปักหมุดข้อความเตือนภัย (Mesh Pinned Alert Board)"** ที่ผู้ใช้สามารถแตะปักหมุดข่าวสำคัญจากเพื่อนบ้านขึ้นแผงเตือนภัยหลักสีแดงด้านบนได้ทันที

6. **แผนที่จำลองออฟไลน์ในตัว (Self-Contained Vector Map)**
   * ใช้ภาพแผนที่เวกเตอร์ในรูปแบบ SVG ความละเอียดสูง แสดงแม่น้ำเจ้าพระยาและโครงสร้างถนนเขตบางพลัดโดยตรงจากตัวเครื่อง ไม่เกิดปัญหาแผนที่กลายเป็นสีเทาเนื่องจากโหลดภาพดาวเทียมไม่ได้
   * รองรับการซูมแผนที่เชิงโต้ตอบ (Zoom + / -) ขยายส่องจุดอันตรายไฟฟ้ารั่วที่ปากซอยจรัญฯ 75 หรือดูศูนย์อพยพหลักวัดอาวุธฯ ได้อย่างคมชัด
   * ระบบหมุดเตือนไฟฟ้ารั่วแบบคลื่นสัญญาณ 2 ชั้นและหมุดศูนย์อพยพส่งเรดาร์แบบ Ping ต่อเนื่อง

7. **ระบบส่งสัญญาณ SOS Morse Code (Emergency SOS Morse Beacon)**
   * ปุ่มเปิดใช้งาน SOS Beacon ขนาดใหญ่แบบไม่มีฝาครอบเพื่อความรวดเร็วในการแตะขอความช่วยเหลือฉุกเฉินทางอากาศหรือทางเรือ
   * ส่งสัญญาณผ่านหน้าจอกะพริบขาว-ดำสลับกัน และพัลส์ไฟฉาย LED (LED Cam Flash Simulation) ถอดรหัสสัญญาณสากลมอร์ส `· · · - - - · · ·` (S-O-S)
   * สามารถกดยกเลิกและกลับมาหน้าแดชบอร์ดได้ทันทีด้วยการแตะจุดใดก็ได้บนหน้าจอ

##  วิทยุเพื่อนบ้าน (Mesh Chat) ทำงานอย่างไรในชีวิตจริง?

ระบบ **Mesh Chat** ที่จำลองขึ้นในแอปนี้ อิงหลักการทำงานของ **Decentralized Mobile Ad-Hoc Network (MANET)**:
* **ไม่ต้องใช้เสาสัญญาณหลัก**: เมื่อเสาสัญญาณมือถือล่มและสายเคเบิลอินเทอร์เน็ตขาด โทรศัพท์แต่ละเครื่องจะใช้เสาสัญญาณในตัว (Wi-Fi และ Bluetooth Low Energy) ส่งข้อความหากันตรงๆ (Peer-to-Peer)
* **การกระโดดข้ามพิกัด (Multi-hop routing)**: หากคุณอยู่ห่างจากศูนย์กู้ภัยเกิน 350 เมตร ข้อความของคุณจะถูกส่งไปหาโทรศัพท์เพื่อนบ้านที่อยู่ใกล้กว่า และส่งต่อไปยังเครื่องถัดไปเรื่อยๆ จนถึงตัวศูนย์กู้ภัยโดยมีระบบเข้ารหัสความปลอดภัย
* **ซอฟต์แวร์แนะนำยามเกิดภัยพิบัติจริง**: ในการใช้งานจริง แนะนำดาวน์โหลดแอปพลิเคชันอย่าง **Briar** หรือ **Bridgefy** ติดเครื่องไว้ล่วงหน้า เนื่องจากสามารถใช้งานพูดคุยออฟไลน์แบบ Mesh Network ได้ทันทีผ่านการเปิด Bluetooth/Wi-Fi บนมือถือ
